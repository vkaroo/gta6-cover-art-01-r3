Sunset Cover Studio — turn a photo and a caption into a multi-panel GTA 6-style poster cover, offline in your browser. Pick a layout (Vice, Streets, Solo), a colour grade (Sunset, Neon, Palm, Noir), crop and position each panel's photo, write the caption, and export a PNG in 1080×1080, 1080×1350 or 1920×1080. Your photos never leave your machine. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` directly in desktop Chrome; the app works with no network request.
